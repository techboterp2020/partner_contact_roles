Overview ✨

The Partner Contact Roles module for Odoo 18 simplifies the classification of your contacts by introducing intuitive "Is a Customer" and "Is a Vendor" checkboxes directly on the contact form. This module bridges the gap between Odoo's abstract ranking system (customer_rank and supplier_rank) and the need for a clear, user-friendly interface.

Features 🚀

  • User-Friendly Checkboxes: Adds clear "Is a Customer" and "Is a Vendor" checkboxes.
  • Automatic Synchronization: Seamlessly syncs checkbox states with Odoo's standard customer_rank and supplier_rank fields.
  • Seamless Integration: Fully compatible with Odoo's native Sales, Purchase, and Accounting modules.
  • Modern Design: Clean interface that maintains Odoo's design principles.

Installation 🔧

  1. Place the partner_contact_roles module folder into your Odoo custom addons path.
  2. Restart your Odoo server.
  3. Activate Developer Mode (Go to Settings > General Settings).
  4. Go to Apps and click on "Update Apps List".
  5. Search for "Partner Contact Roles" in the Apps list and click "Install".

Usage 🧑‍💻

Once installed, navigate to the Contacts application. When you create or edit any contact, you will find the new checkboxes ready to use. Checking or unchecking them will automatically update the contact's rank in Odoo.

Technical Details 💻

  • Model Inheritance: Extends res.partner.
  • New Fields: is_customer (Boolean), is_vendor (Boolean).
  • Logic: Uses compute and inverse methods for robust data synchronization.
  • Dependencies: base, sale_management, purchase.
