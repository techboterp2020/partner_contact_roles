Installation

  1. Place partner_contact_roles in your addons path.
  2. Restart Odoo.
  3. Enable Developer Mode.
  4. Apps → Update Apps List.
  5. Install “Partner Contact Roles”.

Usage

Open Contacts, create or edit a contact, then tick “Is a Customer” or “Is a Vendor”. The module updates customer_rank and supplier_rank automatically.

Technical details

  • Model: extends res.partner
  • Fields: is_customer, is_vendor
  • Logic: compute + inverse methods keep ranks consistent
  • Depends on: base, sale_management, purchase
